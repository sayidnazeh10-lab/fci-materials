# FCI-Materials | منصة حاسبات ومعلومات جامعة أسيوط

منصة ويب أكاديمية متكاملة (PWA) مصممة لطلاب **كلية الحاسبات والمعلومات — جامعة أسيوط** (الأقسام العامة والبرامج الخاصة بنظام الساعات المعتمدة)، بتجمع المواد الدراسية وأدوات تنظيم المذاكرة في واجهة سريعة وعصرية تدعم الوضع الليلي والعمل كـ تطبيق على الهاتف.

## المميزات الرئيسية

### للطلاب
- **تصفح ذكي للمواد:** اختيار المسار الدراسي (نظام / قسم أو برنامج / فرقة / ترم)، مع فتح كل مادة في تاب مستقل وتقسيم ملفاتها إلى تابات منفصلة (`محاضرات` • `سكاشن` • `ملخصات` • `امتحانات سابقة` • `تكليفات`).
- **بحث شامل فوري (`Ctrl+K`):** البحث في كل المواد والملفات وأسماء الدكاترة والوسوم من أي مكان.
- **تتبع التقدم والملاحظات:** علامة إنجاز `✔` لكل ملف، تثبيت المواد المفضلة `⭐`، حفظ الملفات `🔖`، وملاحظات خاصة على كل ملف `📝`.
- **الجدول الأسبوعي ومتتبع الغياب:** إضافة مواعيد المحاضرات والسكاشن، ومتابعة عدد الغيابات مع تنبيه قبل الحرمان.
- **حاسبة GPA والدرجات:** حساب المعدل الفصلي والتراكمي، محاكي المعدل المستهدف، وحاسبة درجة الفاينال المطلوبة.
- **إدارة المهام ومؤقت البومودورو:** مؤقت مذاكرة دائري مع إحصائيات، قائمة شيتات وتسليمات، وكشكول ملاحظات سريع.
- **مزامنة سحابية وخطة مذاكرة ذكية:** نقل بياناتك بين أجهزتك بكود شخصي بدون تسجيل دخول، وتوليد خطة مذاكرة تلقائية قبل الامتحانات، وتصدير المواعيد لملف `.ics`.

### للإدارة (Admin Dashboard)
- **المنظّم الذكي لدرايف (Smart Drive Organizer):** قراءة فولدرات Google Drive الفرعية والاختصارات وتصنيف الملفات تلقائياً حسب الفرقة والترم والمادة والنوع والأسبوع مع فتح المشاركة دفعة واحدة.
- **إدارة جماعية وسلة محذوفات:** تعديل ونقل وإخفاء وحذف جماعي، سلة محذوفات لمدة 30 يوماً، وتصدير CSV ونسخ احتياطي يومي.
- **تكامل تليجرام وفحص صحة الروابط:** إشعارات تلقائية على قناة/جروب تليجرام عند إضافة ملفات جديدة، ملخص أسبوعي، وفحص دوري لصحة روابط الدرايف.

## البنية البرمجية (Architecture)

```text
fci-materials/
├── index.html              # الواجهة الرئيسية الدلالية (Semantic HTML5 + PWA Meta)
├── style.css               # نظام التصميم (CSS Variables, Glassmorphism, Dark/Light, Mobile Nav)
├── app.js                  # منطق التطبيق بالكامل (State, UI, API, GPA, Pomodoro, Admin)
├── sw.js                   # Service Worker (Network-First + Offline Fallback)
├── manifest.webmanifest    # إعدادات تطبيق الويب التقدمي (PWA)
├── icon.svg / icon-*.png   # أيقونات المنصة
└── (Backend) Code.gs       # Google Apps Script API + Google Sheets Database
```

## النشر والتشغيل

1. **الباك إند (Google Apps Script):**
   - انسخ كود الباك إند إلى مشروع Apps Script مربوط بملف Google Sheets.
   - شغّل دالة `setup()` ثم `authorize()` مرة واحدة لمنح الصلاحيات.
   - اعمل **Deploy ← New deployment ← Web app** (Access: Anyone) وضع الرابط في متغير `API` داخل `app.js`.
2. **الواجهة (GitHub Pages):**
   - ارفع ملفات `index.html` و`style.css` و`app.js` و`sw.js` و`manifest.webmanifest` والأيقونات على الريبو، وفعّل GitHub Pages من الإعدادات.
